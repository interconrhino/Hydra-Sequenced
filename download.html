Build your firmware in four steps.

Bring the official 2.2.0 file. The sequencer is added locally.

  1. Download the official firmware

    Hydrasynth Explorer firmware 2.2.0 from ASM. Unzip it for Hydrasynth_Explorer_Firmware_2.2.0.dat. 2.2.0 only.

    Expected checksum

    SHA-256

  2. Drop it here

    Checked against the official 2.2.0 checksum.

    Waiting for a file.

  3. Build the patched file

    Checked byte for byte against the official release before download.

    Version

  4. Flash it with ASM Manager

    Same process as an official ASM firmware update, using the patched file.

    At your own peril. Unofficial firmware, made for my own Explorer and tested only on it (firmware 2.2.0). Never flash it to a keyboard or Deluxe.
    1. Back up your patches in ASM Manager.
    2. Connect the Explorer to your computer over USB.
    3. Power it on holding ARP ON + LATCH. Release when the HYDRASYNTH logo appears. In update mode the screen stays on the logo and doesn't continue booting. If it boots normally, power off and try again.
    4. In ASM Manager's firmware update page, Select File and pick the patched .dat.
    5. Start Update. Don't disconnect until the progress bar completes (2/2).
    6. Reboot the Explorer. Shift+Triplet opens the sequencer.

    Follow ASM's own update instructions where they differ. Back to stock: same steps with ASM's original 2.2.0 file.
