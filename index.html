Features

16 savable phrases, 64 steps

Chords per step. Separate from patches, saved on the synth.

How to
  1. ARP on, Mode → Phrase.
  2. Phrase: 1–16.
  3. Record or edit.
  4. SlotOp → Save>n, push. * = overwrite.

Step recording

One key or chord per step. Length is set when you stop.

How to
  1. Phrase: 1–16.
  2. SeqRec on. SeqStps counts steps.
  3. Play each step in order.
  4. SeqRec off, then Save>n.

Per-step control

Note, velocity, length, rest, tie and ratchet (×2 / ×4 / ×8) on every step.

How to
  1. Shift+Triplet twice, or push SeqStps.
  2. Step: select the step.
  3. Note, Vel, Len, Type: edit it.
  4. SlotOp → Save>n to keep.

Trig conditions

Probability, A:B, 1ST and !1ST, with a live play/skip indicator.

How to
  1. Step editor: select the step, turn TrigCond.
  2. Below 100%: probability. Detent at 100%.
  3. Above: 1:2 … 4:4, 1ST, !1ST.
  4. Step shows the cycle (L2); TrigCond shows + / -.

Euclidean generator

Steps, hits, rotation. Live preview, then apply or cancel.

How to
  1. SlotOp → Eucl?, push.
  2. First screen: Steps, Hits, Rotate, Notes.
  3. Push SlotOp to apply, Exit to cancel.
  4. Save>n to keep.

Phrase lock

Phrase and arp settings stay put while you browse patches. Patches are never changed.

How to
  1. Set up the phrase and arp.
  2. PhrLock on.
  3. Browse. Held values show *.
  4. PhrLock off restores each patch's own settings.

Randomiser

Variations from the phrase's own notes: octave jumps, rests, ties, velocity. Whole phrase or one step.

How to
  1. Whole phrase: hold Random, push SeqStps. Random? appears.
  2. Press Random again to apply, Exit to cancel.
  3. One step: in the step editor, hold Random and push Step.
  4. Step 1 is kept. Save>n to keep.

Trig conditions

Per step. A chord and its ratchets trigger together.

ConditionTriggers
0–99%Probability
100%Always
A:BCycle A of every B. 3:4 = cycles 3, 7, 11…
1STFirst cycle only
!1STEvery cycle but the first

+ / -: plays or skips this cycle (A:B, 1ST, !1ST, while playing).

Phrase lock

Audition patches against the same pattern.

Held across patch changes

  • Phrase, Mode
  • Division, Gate, Swing, Octave, OctMode
  • Length, Ratchet, Chance, StpOffst
  • Arp On, Latch

Held values show *. Patch saves keep each patch's own settings.

Workflow

Separate saving

Phrases save only from SlotOp → Save>n. Patch saves never touch them.

No Safe Edit prompts

Sequencer edits don't flag the patch as edited.

Shortcut

Shift + Triplet: sequencer page. Again: step editor.

Why

I built this for my own Explorer and use it there; every release is tested on my own unit. I'm sharing it so others can enjoy a better standalone Hydrasynth, with no computer needed.

Testing

Emulated from power-on

Every build runs in an emulator against the stock firmware.

Stock when idle

MIDI output and saved data match stock with the sequencer unused.

Audited

Each release is audited independently, then tested on hardware.

Limitations

Explorer 2.2.0 only

Not for the keyboard, the Deluxe or other firmware versions.

Notes stop on patch change

As stock. Retrigger to continue the locked phrase.

Mono patches

Chord steps play as single notes.

Compare

Leaving Compare with unsaved edits can drop locked arp values.
