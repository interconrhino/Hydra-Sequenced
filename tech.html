Finding room

The stock firmware has no free space.

  • New code replaces stock code that can never run: unreachable features, unused helpers, removed tasks. About 26 KB of it exists.
  • A region qualifies only with no callers, no pointers into it and no data reads.
  • The new code is split across those regions and linked to fit them.

Hooks

How the firmware reaches the new code.

  • Each hook replaces one stock instruction with a branch into new code.
  • The new code redoes or replaces that instruction, then returns to stock.
  • Hooks sit in the arp engine's step commit, patch load and save, the UI's page and knob handlers, buttons, RANDOM and the main loop.

Menus

Added through the firmware's own page tables.

  • ClkLock, SeqRec, PhrLock and SeqStps sit on the arp's second page.
  • The step editor is a new two-screen page, reached by a SeqStps push or Shift+Triplet.
  • Item names and ranges live in the firmware's initialised data, which is stored compressed. The patch decompresses it, adds the entries and recompresses it into the original 65,940-byte slot.

Storage

Phrases are kept apart from patches.

  • The bank (16 slots plus a 16-byte lock block) lives in an unused RAM area while the synth runs.
  • It persists to a free window in the synth's flash, read at boot.
  • It is written only by SlotOp → Save>n, inside the firmware's own flash-write sequence with audio paused.
  • Patch saves never touch it, and the stock firmware ignores it.

Playback

Phrase format

Your steps compile to the same event list the factory phrases use. Phrase 1–16 play your slot when it holds a phrase.

Ratchets

×2 / ×4 / ×8 subdivide the step, with a floor of 4 ticks per hit.

Trig conditions

One decision per step, so a chord and its ratchets play or skip together. The cycle counter runs 1–12 and resets on a fresh start, retrig, phrase change or lock change.

Euclidean

Step i is a hit when ((i − rotate) × hits) mod steps < hits. Previewed in a scratch copy; the slot is written only on apply.

Randomiser

Uses the firmware's RNG: octave moves, rests, ties and velocity changes drawn from the phrase's own notes. Step 1 is kept.

Phrase lock

On each patch load the engine gets the locked values; the patch's own are restored behind it, so a saved patch keeps its own arp settings.

The patcher

Ships only the sequencer: new code, hook branches and menu entries. No ASM firmware.

  1. Check

    The input must be the official Explorer 2.2.0 .dat, by size and SHA-256.

  2. Edit

    Code regions and hooks are written into the main image, each hook's original instruction checked first. The data area is decompressed, extended and recompressed.

  3. Verify

    The result must match the release byte for byte, or there's no download. Runs entirely in your browser.
